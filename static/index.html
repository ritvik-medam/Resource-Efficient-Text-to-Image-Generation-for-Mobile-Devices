Documented Failure Cases & Analysis

Mandatory viva requirement: Transparent identification of boundary conditions, edge cases, and mitigation strategies.

Case 1: Legible Typography & Small Text Rendering 1-Step Distillation Bottleneck

Symptom: Prompts requesting specific textual signs (e.g., "A shop with neon sign saying 'COFFEE'") produce illegible pseudo-glyphs in 1-step mode.

Root Cause: Text rendering requires multi-step spatial token attention and fine character guidance. At $N=1$, diffusion prior focuses on global scene composition rather than micro-orthographic details.

Remedy / Mitigation: Fallback to Balanced 4-Step or Quality 8-Step mode when text glyph tokens are detected, or overlay classical OCR/typography post-processing.

Case 2: Complex Spatial Prepositions ("X on top of Y to the right of Z") Attention Binding

Symptom: Multi-object compositional prompts occasionally swap attributes (e.g. "a green cup on a red book" yields a red cup on a green book).

Root Cause: Fast distilled cross-attention collapses multiple object noun-phrases without iterative denoising correction.

Remedy / Mitigation: Structured prompt re-ordering and activating Balanced Mode ($CFG=1.5, Steps=4$).

Case 3: Extreme Low Dynamic Range / Over-Sharpening Halo Artifacts Classical CV Parameter Sensitivity

Symptom: Applying excessive unsharp masking on low-contrast foggy scenes introduces visible high-frequency boundary halos.

Root Cause: Fixed bilateral sigma parameters overestimating edge gradient magnitude in naturally soft/misty imagery.

Remedy / Mitigation: Implemented Adaptive Parameter Selection: pipeline calculates initial image variance and auto-scales CLAHE clip limit and unsharp strength dynamically.
