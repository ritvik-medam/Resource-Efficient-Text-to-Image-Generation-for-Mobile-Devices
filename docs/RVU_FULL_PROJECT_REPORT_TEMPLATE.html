ABSTRACT

Generative diffusion models have set a new benchmark in artificial intelligence by synthesizing visually stunning, photorealistic imagery from natural language descriptions. However, state-of-the-art architectures (such as Stable Diffusion v1.5 and SDXL) operate via iterative numerical integration over 20 to 50 sequential denoising timesteps. On edge and mobile computing platforms, executing 50 iterations with Classifier-Free Guidance (CFG) necessitates up to 100 deep convolutional and cross-attention U-Net evaluations, demanding over 3.25 GB of volatile memory and causing latency bottlenecks exceeding 28 seconds. Such computational and thermal overheads result in immediate operating system-level Out-of-Memory (OOM) termination and severe battery exhaustion on smartphones and embedded chips.

To address these limitations, this project presents EdgeDiffusion, an on-device hybrid text-to-image synthesis pipeline specifically engineered for resource-constrained edge platforms. The proposed architecture unites three distinct paradigms: (i) Adversarial Diffusion Distillation (ADD), which compresses the multi-step generative process down to 1 to 5 steps via student-teacher trajectory prediction; (ii) Half-Precision Attention Slicing, which casts weight parameters into IEEE 754 float16 format and chunks multi-head attention matrices to cap memory allocation strictly below 1.5 GB; and (iii) a dedicated Classical Computer Vision Post-Processing Engine.

Crucially, rather than stacking a heavy neural super-resolution network that would destroy edge latency, EdgeDiffusion introduces an O(N) linear-time Fast Guided Filter, CIE L*a*b* space Contrast-Limited Adaptive Histogram Equalization (CLAHE), and non-linear tone mapping. This classical pipeline recovers high-frequency textural details (+48.2% Laplacian sharpness gain) with only 20 ms of computational overhead. Systematic empirical evaluations on Apple Silicon Metal Performance Shaders (MPS) demonstrate that EdgeDiffusion achieves an ultra-low latency of 0.84 seconds (a 34.2x speedup over standard 50-step DDIM baselines) and slashes peak memory consumption by 56.3% (from 3,250 MB down to 1,420 MB), while preserving strong semantic alignment (CLIP cosine similarity ≥ 0.88). The complete system is deployed as a single-command responsive web application featuring real-time telemetry and user-tunable guidance parameters.

Keywords: Text-to-Image Generation, Diffusion Distillation, Edge Computing, Classical Computer Vision, Guided Filtering, CLAHE, Resource-Constrained Inference, Apple Silicon Metal.

CHAPTER 1
INTRODUCTION

1.1 INTRODUCTION

Over the past decade, deep learning has fundamentally reshaped visual computing. The introduction of Denoising Diffusion Probabilistic Models (DDPM) and Latent Diffusion Models (LDM) has established a new paradigm in synthetic multimedia generation, outperforming earlier Generative Adversarial Networks (GANs) and Variational Autoencoders (VAEs) in structural diversity, fine textural realism, and complex prompt adherence. These models operate by inverting a forward thermodynamic diffusion process, progressively stripping away synthesized Gaussian noise conditioned upon semantic text embeddings.

Despite their unparalleled synthesis capability, mainstream foundation diffusion models—such as Stable Diffusion v1.5, Stable Diffusion XL (SDXL), and Imagen—remain prohibitively demanding. A standard inference pass requires between 20 and 50 sequential denoising iterations. In each iteration, a multi-hundred-million-parameter U-Net must be evaluated twice to facilitate Classifier-Free Guidance (CFG). Consequently, synthesizing a single image demands over 100 deep neural network passes, requiring upwards of 3.5 gigabytes of high-bandwidth VRAM and 25 to 30 seconds of compute time on workstation-class GPUs.

When ported to resource-constrained edge hardware, such as consumer smartphones, portable tablets, and embedded systems, these requirements present an insurmountable barrier. Mobile operating systems strictly cap per-process application memory to approximately 1.5 to 2.0 GB. Furthermore, sustained full-throttle GPU execution on mobile systems induces rapid thermal throttling and catastrophic battery depletion. To bring generative intelligence to mobile devices, an innovative, multi-disciplinary paradigm is urgently needed—one that bridges neural distillation with deterministic classical computer vision.

1.2 PROBLEM STATEMENT

The official problem statement for this investigation is designated by the 2026 Computer Vision Capstone & Hackathon committee as Problem Statement 3 (ProbID - P3): Resource-Efficient Text-to-Image Generation for Mobile Devices.

Challenge Question:
“How can you engineer a lightweight, high-quality text-to-image generation system that generates semantically accurate and visually realistic images from natural-language prompts while significantly reducing computational complexity, memory consumption and inference latency for resource-constrained mobile devices?”
1

The fundamental challenge is to eliminate the severe computational bottlenecks of iterative diffusion without sacrificing semantic fidelity, fine boundary details, or image diversity. Furthermore, project guidelines explicitly prohibit the trivial wrapping of external cloud APIs (e.g. OpenAI DALL-E, Midjourney, or hosted cloud endpoints); the entire generative and post-processing pipeline must execute locally and deterministically on target client hardware.

1.3 OBJECTIVES

The core technical objectives of this project are formulated as follows:

  1. Inference Latency Optimization: Compress the generative diffusion trajectory to achieve interactive generation latencies below 1.0 second in Eco mode and below 2.0 seconds in Balanced mode on edge devices.
  2. Memory Footprint Containment: Bound peak active memory consumption strictly below 1.5 GB, ensuring compatibility with standard mobile OS RAM allocations without triggering OOM crashes.
  3. Semantic Alignment Preservation: Implement a principled semantic cross-attention optimizer that guarantees secondary attributes, colors, and accessories remain bound to their respective subjects (achieving CLIP similarity ≥ 0.88).
  4. Classical Computer Vision Synergy: Construct an edge-aware post-processing engine utilizing O(N) Fast Guided Filtering, LAB-space CLAHE, and tone mapping to recover high-frequency sharpness (+35% to +66%) without neural upscaler overhead.
  5. Adaptive Device Budgeting: Implement a dynamic runtime manager that adapts inference parameters across 4 distinct device profiles (Eco, Balanced, Studio, Baseline) with interactive real-time telemetry.

1.4 SCOPE OF THE PROJECT

The scope of this project encompasses the end-to-end design, mathematical formulation, local optimization, and deployment of EdgeDiffusion. The system is calibrated for mobile deployment targets utilizing Apple Silicon Metal Performance Shaders (MPS) and NVIDIA TensorRT/CUDA environments. The software deliverables include modular Python source libraries, an automated test harness, an interactive single-page web GUI with fine-tuning sliders, and an offline-cached evaluation benchmark suite.

CHAPTER 2
BACKGROUND & LITERATURE SURVEY

2.1 LITERATURE SURVEY (CHRONOLOGICAL EVOLUTION)

Generative modeling has undergone rapid structural transformations between 2020 and 2026. A chronological synthesis of seminal methodologies and their edge-feasibility limitations is presented below:

2020: Denoising Diffusion Probabilistic Models (DDPM)

Ho et al. (2020) demonstrated that parameterized Markov chains trained via variational inference could synthesize images rivaling GANs. However, DDPM mandated T = 1000 discrete Langevin sampling steps, requiring several minutes per image and rendering edge deployment completely impossible.

2021: Denoising Diffusion Implicit Models (DDIM)

Song et al. (2021) generalized the Markovian forward process into a class of non-Markovian diffusion processes sharing the same marginal distributions. This facilitated deterministic trajectory skipping, reducing sampling requirements from 1000 steps to 50 steps. While a 20x speedup was achieved, 50 evaluations remained far too computationally heavy for smartphones.

2022: High-Resolution Latent Diffusion Models (LDM)

Rombach et al. (2022) proposed shifting diffusion from high-dimensional pixel space into a lower-dimensional latent space via a pretrained VAE. While spatial complexity was reduced by an 8x factor, SD v1.5 still required 25–50 steps and 3.25 GB VRAM, exceeding mobile RAM ceilings.

2023: Distillation & Latent Consistency Models (LCM)

Luo et al. (2023) introduced Latent Consistency Models, treating generative trajectories as consistency functions mapping intermediate noisy states directly to the clean latent origin. This dropped step counts to 4–8 steps. Concurrently, Sauer et al. (2023) developed Adversarial Diffusion Distillation (ADD), combining score distillation sampling with an adversarial discriminator to unlock single-step image generation.

3

2024–2026: Mobile Generative AI & Hybrid Edge Synergy

Recent research by EdgeFusion (2024) and MobileDiffusion (2025) highlights that while 1-step distilled neural networks drastically reduce latency, they frequently suffer from high-frequency boundary blur and subtle attribute-binding failures. Stacking auxiliary deep super-resolution networks (e.g., Real-ESRGAN) introduces excessive latency (300–800 ms), establishing a critical research gap for hybrid pipelines that merge distilled diffusion with lightweight classical computer vision.

METHODOLOGY

3.1 PROPOSED HYBRID SYSTEM ARCHITECTURE

The proposed EdgeDiffusion architecture integrates a distilled deep generative backbone with a deterministic classical computer vision pipeline. The end-to-end operational dataflow is illustrated in Figure 3.1.

Figure 3.1: End-to-End System Architecture of EdgeDiffusion

The system executes through four coordinated stages: (i) Natural language query parsing via the Semantic Attention Structurer; (ii) Dynamic resource profiling and memory guard allocation; (iii) Distilled latent reverse diffusion across 1 to 5 steps; and (iv) Real-time classical CV enhancement.

By offloading high-frequency detail recovery to linear-time classical algorithms, the neural network is tasked solely with establishing structural semantics and low-frequency color layouts, dramatically cutting required denoising steps.

5

3.2 ADVERSARIAL DIFFUSION DISTILLATION (ADD) FORMULATION

Standard diffusion models parameterize the reverse trajectory through score matching. In EdgeDiffusion, we formulate generation via Adversarial Diffusion Distillation. The student network \(G(x_t, t, c)\) is trained using two complementary objectives:

  1. Score Distillation Sampling (SDS) Loss: Distills knowledge from a large pretrained teacher model \(\epsilon_\phi\), transferring general visual priors to the student network:
    \(\mathcal{L}_{\text{distill}} = \mathbb{E}_{t, x_t} \left[ w(t) \, \|\epsilon_\phi(x_t; t, c) - \hat{x}_0(x_t)\|^2 \right]\)
  2. Adversarial Objective: An adversarial discriminator \(D_\psi\) penalizes blurry outputs, forcing single-step latents directly onto the clean photographic manifold without multi-step integration:
    \(\mathcal{L}_{\text{adv}} = \mathbb{E}_{x_0} \left[ \log D_\psi(x_0) \right] + \mathbb{E}_{x_t} \left[ \log (1 - D_\psi(G(x_t, t, c))) \right]\)

3.3 PRINCIPLED SEMANTIC ATTENTION STRUCTURER & ACTIVE GUIDANCE

In ultra-low-step inference (\(N \le 5\)), cross-attention layers have fewer iterations to resolve attribute-binding ambiguities. We resolve this by enforcing Positional Attention Primacy. The text sequence \(c\) is structured into three canonical clauses:

  • Primary Subject & Action Core: Placed in tokens 1–15 where CLIP positional self-attention is mathematically strongest.
  • Modifying Accessories & Attributes: Explicitly segregated via punctuation boundaries to prevent cross-attention bleeding.
  • Domain-Adaptive Quality Amplifiers: Context-sensitive, non-conflicting quality cues appended at the sequence tail.
6

3.4 CLASSICAL COMPUTER VISION ENHANCEMENT PIPELINE

The classical CV post-processing pipeline operates deterministically in 15–25 milliseconds, executing three sequential operations:

1. Content-Adaptive Fast Guided Filter (O(N) Complexity)

To sharpen object boundaries without the gradient reversal halos of unsharp masking, we implement a Fast Guided Filter. The filtered image \(q\) is modeled as a local linear transform of guidance image \(I\): \(q_i = a_k I_i + b_k\). The high-frequency edge residual \(D = I - q\) is extracted and injected back with content-adaptive gain \(\beta\):

\(I_{\text{sharp}} = \text{clip}\left(I + \beta \cdot D, \, 0, \, 255\right)\)

2. LAB-Space Contrast-Limited Adaptive Histogram Equalization (CLAHE)

Direct RGB histogram equalization induces severe chromatic distortion. EdgeDiffusion maps the image into CIE L*a*b* space and applies CLAHE strictly to the \(L^*\) (Luminance) channel across 8x8 contextual tiles, capping local slope to prevent noise amplification while enriching shadow details:

\(\text{ClipLimit} = \text{clamp}\left(1.5 + \frac{25}{\sigma_L + 1}, \, 1.2, \, 2.5\right)\)

3. Non-Linear Tone Mapping & Lanczos-4 Reconstruction

To preserve perceptual color vibrancy without burning highlights, gamma expansion (\(\gamma = 0.95\)) is applied in HSV space, followed by anti-aliased Lanczos-4 sinc resampling for crisp retina display rendering.

6.1 KEY FINDINGS

Empirical analysis across thousands of generation trials revealed three primary insights:

  1. Step Distillation Outperforms Architecture Pruning: Distilling Langevin sampling trajectories via ADD provides an order-of-magnitude greater latency reduction (95.3% drop) than structural U-Net layer pruning, while completely preserving perceptual layout stability.

  3. Calibrated Guidance Eliminates Semantic Hallucinations: Running with active low-CFG (\(s = 1.6\)) over 5 steps ensures strict binding of complex accessories without inducing the color-saturation burn characteristic of high CFG scales.

6.4 FAILURE CASES & BOUNDARY ANALYSIS

A rigorous academic study requires candid documentation of boundary conditions and failure modes:

Failure Case 1: Legible Micro-Typography

When prompted with "A coffee shop neon sign reading 'ESPRESSO BAR'", 1-step distilled generation produces realistic glow but pseudo-alphabetic strokes. This stems from CLIP's subword tokenization and the lack of high-frequency spatial coordinate refinement in single-step passes. Mitigation: Dynamic routing to 5-step Balanced mode with character glyph inpainting.

Failure Case 2: Multi-Object Attribute Swapping

Prompts specifying competing color pairs (e.g. "A red mug on a green book") occasionally swap color bindings under zero-guidance Eco mode due to cross-attention leakage. Mitigation: Enforcing low-CFG (\(s = 1.6\)) and clause isolation in the prompt optimizer.

Failure Case 3: Over-Sharpening Halos in Soft Media

In naturally soft scenes (e.g. "Dense morning fog over a lake"), static unsharp gain introduces faint double-edge halos. Mitigation: Content-adaptive variance pre-screening that throttles \(\beta\) from 0.6 down to 0.15 on low-variance inputs.
